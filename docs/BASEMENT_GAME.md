# 负一楼禁区（0.21.0）

本文件记录内部规则和验收边界，不作为游玩中的自动教程。玩家从纸条、声响、场景及短警报获取线索。

## 地图与目标

- 原25列地图向南扩为54行。旧更衣室南侧16级石阶下降4.8米，玩家和追捕者按同一地面高度连续行走，不切换为传送场景。
- 地下入口、泵房、储藏间、巡检廊、冷藏室、集水池、中央巡廊由多条通路连接；有三个新衣柜和两枚新水晶。场景使用独立绘制材质和秘密壁画，环境光地面0.055、地下0.025，手电强度仍5，局部维护灯仅照小范围。
- 原钥匙/供电/断线钳/手轮/泄压/排水后，需要在地下储藏间找到备用继电器，恢复泵房供电、打开集水池污水闸，返回上层检修室剪网逃生。任务由物品、已搜索来源及机关状态校验，不能只走到出口取胜。
- M只显示探索地图，可切地面和负一楼，玩家箭头只画在其所在楼层；未探索房间和物品不泄漏。Esc只有功能按钮；纸条独立阅读、暂停世界，并可从菜单回看已发现内容。

## 敌方能力

仅进入负一楼时推进能力轮次。感测与瞬移共享串行施法过程：等待30秒，先等概率抽选其一；若被选技能未冷却则等该技能，不能悄悄改选；随后每秒第n次判定以n/30概率发动，第30次保证发动。发动后有3秒模型时间预警，执行完再等30秒。感测冷却35秒、瞬移45秒，从执行结束计起。

感测以结算前0.4秒内的真实位移判移动，静止命中20%、移动80%，顶墙或转头不算移动。命中后记录一次位置线索、总暴露100并追捕；藏柜时命中也会知道该柜，未命中不读隐藏位置。位置线索借用视觉来源分，HUD短时标记“技能感测”，普通视觉仍需真实视野。

瞬移从同层连通的合法格子抽样，排除墙、家具安全边距、楼梯及玩家附近3格（4.5米）保护区；最远12格。权重为`exp(-r²/50)`，相当于以玩家为中心、sigma5格的二维高斯在合法区域条件采样，不总贴脸。没有合法点则施法失败。瞬移后先在落点调查，后续需普通声光线索，不能持续读取玩家位置。

冻结暂停感测/瞬移蓄势、预警及冷却；离开地下取消尚在预警的施法，未执行不消耗冷却。暂停、纸条和CG不推进模型时间。UI只有两种技能的充能条、黑白奶蛙头像、短警报和扫描横扫条，不显示秒数、概率或操作建议。

## 感官污染

独立于上述轮次：正常10秒后进入每秒递增判定，第n次概率n/30，第30次必定施加。污染30秒后自动恢复正常，再开始下一轮。离开地下清除并重置；冻结可暂停未施加时的蓄势，但已经附加的污染会按世界时间自行消退。

污染时暴露总分、三来源及其贡献全部使用独立seed和3Hz合成值，仍经同一个非线性贡献算法显示，绝不写回真实AI分数或消耗其随机数。隐藏真实追击建议和距离提示以免泄漏真值，脚步、角色动作及显形晶仍是真实反馈。只标记“被干扰”，不显示剩余时间或持续进度条；结束后自动切回真实值。

## 听觉与公平性

基础听距：步行13米、蹲行5米、奔跑24米、喘息22米；近处基础速率22/9/48/34分每秒，按距离平方衰减，墙门听距乘0.7。0输入/0位移没有脚步分；听距外为0，没有最低50分。可闻移动每秒以`min(0.75, 实际听觉涨分率/48)`概率调查当时声源，极微弱声音的概率也趋0；明显玻璃/门/电源/阀门声会直接引发可闻范围内的调查，不等暴露45，也不直接强制追击100。

藏柜目击遵守同一前方视野，不能从后脑看见玩家。追捕者只记住被目击或感测到的柜子，检查旧空柜不会抓到躲在另一间房的玩家。直接实体接触仍可抓捕。

## 存档与验证

用户明确要求整个游戏不兼容旧格式。代际`2026-10-b1-v2`与逃生快照v2启用；不匹配时只重置nwaxz拥有的IndexedDB和本地键，匹配代际的日常修复保留进度。旧备份拒绝，损坏progress格式单键重置；权限/事务错误必须报告，不能假装已保存或无限迁移。

三种预选AI种子用同一参考物理玩家验证：202完成完整地下往返约595秒、被抓2次，101/303因新追捕压力失败；失败验证三次捕获封顶和已取得进度合法，不能声称三条均通关。几何与任务不随该随机种子改变，完整地图目标链有真实AI通关证明。未关闭敌人或技能，未注入物品、瞬移玩家或扩充生命。测试机器人不等同真人最优策略或真机性能。具体浏览器、构建和发布证据见[验证记录](VERIFICATION.md)与[Issue #62](https://github.com/lingyunmo/nwaxz/issues/62)。
