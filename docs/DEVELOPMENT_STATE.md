用户已明确授权持续推进项目，不因单轮结束而主动停工。每批在完成浏览器验收和 `pnpm check` 后，按 PR、Verify、合并、CI 部署及公网 SHA 验证流程发布。生产操作只限 nwaxz；不改动其他生产服务或共享资源。
