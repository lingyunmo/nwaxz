# 开发状态与后续计划

## 已发布版本 0.5.0

PR #12 已合并至 main，发布提交为 `548071e6ba57e368ad8edc50a03964f80e085488`。[GitHub Actions run 38650527805](https://github.com/lingyunmo/nwaxz/actions/runs/38650527805) 的 Verify、Build image、Deploy nwaxz 均成功，本轮公网 smoke 精确核对该 SHA。Chrome 点击“有新版本”更新后，确认旧泡泡币从 9/18 保留并扩展为 9/24。

0.5.0 包含八关及水草、海绵机制。发布前 `pnpm check` 通过 31 项业务测试和 1 项 PWA 检查；八关模拟路线均以半径 25 挖掘并收齐三枚泡泡币。Chrome 本地候选版实玩两道新增关卡并各获 3/3 泡泡币，验证 390 × 844 触摸、键盘机关操作、暂停画面冻结和离线冷重载；具体记录见 [VERIFICATION.md](VERIFICATION.md)。

## 0.6.0 发布前验收快照

第四章“暖暖水工坊”新增 `valve-wind-relay` 与 `sponge-relay`，总计十关。独立暖色绘制背景用于场景、土层与侧边衬景。第九关结合有限阀门、风扇和折反水道；第十关结合有限阀门与两块 128 滴海绵，`E` 选择第一块有库存的海绵，触摸可分别挤水。

`pnpm check` 的 36 项业务测试和 1 项 PWA 检查通过。十关均有全币模拟路线，另有组合机关不能省略及有限水量回归检查。Chrome 在 390 × 844 视口实玩两个新关并全币通关，验证触摸挖土/开阀/上层挤水与 F/V/E 键；844 × 390 横屏 HUD 不溢出。暂停画布两次摘要相同；候选 `index-BEbhUYh2.js` 断网冷重载保留两关最高分、最快时间与 30/30 泡泡币，可离线进入双海绵关、加载工坊美术并暂停。无应用控制台错误，已恢复网络、触摸模拟及视口。

这是发布前候选记录；主分支发布工作流及公网精确 SHA 必须另行核对。0.5.0 发布证据见上文。后续继续以小批新增机关组合及关卡，并保留原存档；云端同步尚未实现。

## 持续推进与范围

用户已明确授权持续推进项目。每批完成浏览器验收和 `pnpm check` 后，按 PR、Verify、合并、CI 部署及公网 SHA 验证流程发布。生产操作只限 nwaxz，不修改其他生产服务或共享资源。

项目已建立长期目标和 heartbeat automation（`nwaxz`，每 30 分钟关联当前 thread）以记录续做策略；它们不能保证电脑关机或任务环境不可用时继续运行。推进过程中不消费额度券。源码仓库保持公开，main 分支保护照常执行。文档与代码不得记录真实服务器地址、私钥或访问令牌。
