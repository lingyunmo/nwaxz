## 已授权的持续工作

用户已明确授权持续推进此项目，不因单轮结束而主动停工。本轮优先完成 0.2.0 最终验收与限定范围部署；之后再逐批增加关卡。已授权的常规路径为 PR、Verify 和自动部署。生产操作仅限 nwaxz，不触碰其他生产服务、容器、DNS 或共享资源。

长期关卡计划逐批加入风扇、喷水阀、污水、水草和海绵。每种机制都需要可理解的交互、对应物理行为和可解谜用途；场景背景使用绘制好的美术资源，交互逻辑由代码实现，不把机制做成单纯装饰。
