# 开发状态与后续计划

## 已发布版本 0.3.0

本批合并前核对线上 0.3.0，提交为 `13f2c2870e8832e30b860fa14d04dbbad0b08ad9`。[GitHub Actions run 38641714810](https://github.com/lingyunmo/nwaxz/actions/runs/38641714810) 的 Verify、Build image、Deploy nwaxz 全部成功，公网 smoke 精确核对该 SHA。Chrome 更新后确认第二章选关入口正常，原存档的 9 枚泡泡币仍保留。

与 0.2.0 发布后的服务器只读基线相比，21 个其他容器的 ID、StartedAt 和 RestartCount 均相同；不记录服务器地址。

## 当前开发批次 0.4.0

本批只新增第三章第六关 `clean-water-only` 和基础污水机制：关卡额外生成 64 滴紫色污水，水滴接触会传播污染，污水不收泡泡币、不计入清水 delivered；污水流入管道后增加 `dirtyDelivered`，触发失败/重试且不写成绩，并显示奶蛙失败姿态。游戏前后端版本均从 `package.json` 读取；章节分页通用化，存档仍为 v1 格式。

`pnpm check` 已通过 25 项业务测试和 1 项 PWA 构建检查。六关均通过模拟路线测试，能够收齐 3 枚泡泡币并满足通关条件。Chrome 已实玩两条污水路线：失败和重试不写成绩；手机触摸正确路线 100 滴清水、3/3 泡泡币；断网冷重载保留成绩和 18/18 泡泡币，可离线进入第三章并暂停。本段记录合并前状态，发布须另核对工作流与公网精确 SHA。

园景图片已准备，但尚未接入植物或海绵玩法。这些机制留待下一开发批次；当前只发布污水基础机制。

## 持续推进与范围

用户已明确授权持续推进项目。每批完成浏览器验收和 `pnpm check` 后，按 PR、Verify、合并、CI 部署及公网 SHA 验证流程发布。生产操作只限 nwaxz，不修改其他生产服务或共享资源。

项目已建立长期目标和 heartbeat automation（`nwaxz`，每 30 分钟关联当前 thread）以记录续做策略；它们不能保证电脑关机或任务环境不可用时继续运行。推进过程中不消费额度券。源码仓库保持公开，main 分支保护照常执行。文档与代码不得记录真实服务器地址、私钥或访问令牌。
