# 开发状态与后续计划

## 已发布版本 0.4.0

最近核对的发布提交为 `3dbd632c4c1a7073d707fd593edc70cca57f2298`。[GitHub Actions run 38643628629](https://github.com/lingyunmo/nwaxz/actions/runs/38643628629) 中 Verify、Build image、Deploy nwaxz 均成功，公网 smoke 精确核对该 SHA。该版本包含六关及 `clean-water-only` 清污分流机制。Chrome 更新后已核对公网第三章第六关入口、旧存档的 9 枚泡泡币及正常解锁限制。

## 当前开发批次 0.5.0

当前分支 `codex/plant-sponge-levels` 快照共有八关。新增 `garden-gate` 水草关：水草阻挡清水，吸收 12 滴污水后枯萎；应先打开 12 滴、spread 0 的污水阀，再打开 208 滴清水阀，操作支持 `B`/`V`。新增 `sponge-transfer` 海绵关：容量 160 滴，点击或按 `E` 将库存放入队列，以 80 滴/秒向下释放并保留水种类；1 秒内避免原海绵立即重吸，未挤水不能通关。水量守恒统计涵盖水草吸收、海绵库存和队列。旧 v1 存档格式与原六关保持兼容。

当前 `pnpm check` 通过 31 项业务测试和 1 项 PWA 构建检查；八关模拟路线均以半径 25 挖掘并收齐三枚泡泡币。Chrome 已实际通关两道新关卡，各获 3/3 泡泡币；验证 390 × 844 真实触摸划土、B 键污水阀、触摸清水阀、E 键及触摸挤水。海绵暂停期间两次画布像素摘要一致。精确候选构建断网冷重载保留两关最高分、最快时间和 24/24 泡泡币，可离线进入水草关并加载道具；无应用控制台错误。测试结束已恢复网络、触摸模拟和视口。 本段记录合并前验收，发布仍须核对 main Actions 和公网精确 SHA。

## 持续推进与范围

用户已明确授权持续推进项目。每批完成浏览器验收和 `pnpm check` 后，按 PR、Verify、合并、CI 部署及公网 SHA 验证流程发布。生产操作只限 nwaxz，不修改其他生产服务或共享资源。

项目已建立长期目标和 heartbeat automation（`nwaxz`，每 30 分钟关联当前 thread）以记录续做策略；它们不能保证电脑关机或任务环境不可用时继续运行。推进过程中不消费额度券。源码仓库保持公开，main 分支保护照常执行。文档与代码不得记录真实服务器地址、私钥或访问令牌。
