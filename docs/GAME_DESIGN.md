# 游戏设计

## 核心体验

玩家在浴室场景中挖开泥土，引导水流进入浴缸。每关需接到 100 滴水才算通关；途中有 3 枚泡泡币可收集，石块不能挖穿，需要绕路。当前三个关卡分别是 `first-bath`（第一缸水）、`detour`（绕个小弯）和 `last-drop`（曲曲折折）。

## 游戏流程

主界面可开始普通模式或继续尚未完成的关卡。普通模式选关界面展示解锁状态、泡泡币、最高分和最快时间。进入关卡后，玩家可暂停、确认重来或返回选关；成功时结算显示泡泡币、用时和分数，并可进入下一关或再次挑战。浏览器支持时会请求原生全屏；不支持时仍使用全视口布局。

首次有效挖土时启动计时。暂停或页面进入后台后暂停计时，恢复时继续。分数公式：

```text
1000 + 500 × 泡泡币数量 + max(0, 1000 - floor(elapsedMs / 100))
```

因此基础分为 1000，每枚泡泡币增加 500，时间奖励最多 1000，满泡泡币最高 3500 分。每关的最高分和最快时间是两个独立纪录：新成绩只更新对应的较优指标，不让另一项退步。IndexedDB v1 旧存档可继续使用；旧记录没有的分数或时间保持为空，不推算或补造。

## 水流、反馈与辅助

水流由 208 粒子求解器运行，固定 120 Hz 步进，使用空间分桶；土壤以 CELL8 网格挖掘，石块保持不可挖。设置提供合成背景音乐、音效、设备震动、简化动作和平衡/高清画质。音乐默认关闭；声音由 Web Audio 即时合成，不使用外部录音素材。角色的 12 种姿态（原有 8 种和新增 4 种）平滑混合，并带有连续呼吸摆动。绘制素材和排版参考见 [ART_V2.md](ART_V2.md)。

## 后续关卡方向

后续计划逐批引入风扇、喷水阀、污水、水草和海绵。每种机制都应改变玩家的选择或水流行为，并通过可见反馈帮助玩家理解规则。关卡背景作为美术资源绘制；风向、阀门开关、污染、阻挡和吸水等交互与模拟由游戏代码实现。扩关顺序以玩法清晰、可验证和稳定为准，不预设具体发布版本。
