# 加载画面与循环 CG

## 当前实现

加载页全视口播放五张已有原画，每张8秒，淡入切换并循环。支持上一张、下一张、暂停；后台停止轮播，返回后继续。原图文件未修改，没有新增图片下载包。两张旧浴场场景补充到轮播，所有图片合计约550KiB，均已在原有完整预缓存内。

轮播由独立的小脚本启动，不必等游戏主模块下载完成。0.31.0起底部读取启动包的实际字节进度；约324KB的启动包准备好后立即进入首页，不等待全游戏约106MiB或轮播结束。其他资源按模式/关卡使用时准备并缓存，完整离线包改为设置内主动下载。没有降低原图精度或修改生产网络；具体策略和验收边界见[启动与离线](FAST_STARTUP.md)。

视频尚未提供，没有添加占位文件或额外的视频网络请求。已支持图片与视频混排：视频静音、内联播放，一次播放完即进入下一项，整份列表循环。浏览器拒播、加载失败或播放中卡住时跳过，之前的图保留作底图。最长播放30秒；用户手动暂停与页面隐藏也会暂停，离开加载页后清理播放器、定时器、监听。加载页CG和局内开场/被抓CG相互独立。

系统“减少动态效果”或游戏同名偏好开启时关闭画面缩放与淡入，仍可手动换图/暂停。

## 视频交付要求

- 建议先做一条12秒、16:9、1920×1080、24或30fps的无缝循环片；角色和重要动作放在中央三分之一区域，兼容手机竖屏裁切。
- 不在生成画面里烧录游戏名、文字、进度条、字幕、黑边或水印。左上留出标题空间，下方四分之一留作加载进度。
- 以现有逃生版奶娃和浴场走廊为参考，保持角色比例、脸和材质一致，不改成普通可爱版；不要直接复制其他游戏角色、地图或标志。
- 交付MP4（H.264、yuv420p、faststart）。保留生成原文件，不自行压缩或降低画面分辨率。加载页默认静音，音乐由游戏自己的声音设置管理。

### 可直接使用的提示词

请严格以我上传的恐怖奶娃角色图和废弃浴场场景图为视觉参考，制作12秒无缝循环的游戏加载页CG，16:9，1920×1080。废弃浴场深夜，潮湿墨绿瓷砖、锈蚀水管、微弱暖黄壁灯，空气里薄雾缓慢流动，地面浅水映出灯光。恐怖奶娃站在画面中央的走廊深处，保留参考图的肥大黄色身体、浅色腹部、黑暗眼窝和夸张牙齿，不能可爱化。镜头全程固定，构图有强烈景深。0至4秒奶娃缓慢呼吸，手指轻动；4至8秒它抱住肚子无声怪笑，肩腹轻轻起伏；8至12秒慢慢恢复最初站姿，头和双手回到起点。灯光仅轻微明暗变化，不频闪，不突然全黑，雾和水波平缓连续。首尾的机位、角色位置、姿态、灯光和雾感一致，衔接后看不出剪切。角色完整位于画面中央三分之一区域，左上和底部四分之一保持暗且干净，给游戏标题和加载进度留空间。风格为有质感的恐怖游戏过场，压迫、诡异，动作平滑克制。没有追逐、扑脸、切镜、镜头推进、血腥伤害；没有文字、字幕、HUD、logo、水印或黑边，不添加其他角色。

生成时附：`public/assets/scenes/escape-cover-v1.webp`（形象/走廊），需要细化笑脸时另附现有恐怖版奶娃原图。不要拿普通模式的可爱奶娃作主参考。四视图不是本次固定镜头CG的必要条件。

## 后续接入

视频准备好后，放入例如 `public/assets/video/loading-bath-v1.mp4`，在 `public/assets/loading/playlist.json` 的 `items` 中插入：

```json
{ "type": "video", "src": "/assets/video/loading-bath-v1.mp4", "title": "长廊深处", "seconds": 15 }
```

`seconds` 为最多展示时长，提前播完就换下一项；图片为展示时长。只接受本项目 `/assets/` 下的图片或MP4路径。若视频超过现有单文件8MiB预缓存上限，先调整经验证的资源预存方案，不擅自重压缩用户源文件。同步更新 `ops/pwa.test.mjs` 的视频白名单，执行完整检查与离线/拒播验收后按PR发布。当前发布没有这段视频。
