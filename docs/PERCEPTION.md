# 极限恐怖感知规则（0.19.0）

声音、灯光、视觉都从0分开始，没有50分保底。未被听见、手电没照中奶蛙、奶蛙也看不到玩家时，三路分数会逐渐退回0。追击会保留最后感知位置的短期记忆，不会关灯就立刻忘记玩家。

## 总暴露与贡献

总分为 `100 × [1 − (1 − 声音/100)(1 − 灯光/100)(1 − 视觉/100)]`。原始风险达到99.5时封顶100，避免三路都接近满分却无法触发追击。

| 声音 | 灯光 | 视觉 | 总分 |
| --- | --- | --- | --- |
| 0 | 0 | 0 | 0 |
| 50 | 0 | 0 | 50 |
| 50 | 50 | 0 | 75 |
| 50 | 50 | 50 | 87.5 |
| 99 | 99 | 0 | 100 |
| 100 | 任意 | 任意 | 100 |

三路贡献按线索重叠程度公平分摊，即平均所有六种加入顺序的边际风险。以某一路的比例x、另两路y/z计算，其原始贡献为 `100x × [1 − (y+z)/2 + yz/3]`。相加等于原始总分；封顶或追击锁定时按比例缩放到实际总分，百分比为贡献占比。HUD用“≈”表示四舍五入值，因此显示值可能有舍入差。没有实际来源的旧追捕存档会把其已知追捕记忆迁移为视觉分，确保贡献与状态一致。

45分起警觉，三路涨分速度为基础的1.5倍；有新线索时刷新6秒警觉记忆。100分开始追击并播放恐怖笑声。追击期间总分锁定100，失去视线、可闻声音和手电光源3.5秒后转为搜索最后线索。奶蛙不能直接读取新的无声藏身位置。明确看到玩家钻柜会记住这个藏身位置；直接碰到玩家也会抓捕。

## 三路感知

- **声音**：只根据实际位移产生脚步，顶墙无位移不涨。步行/蹲行/跑步的基础听距为7.5/3/15米，贴近时基础每秒16/7/36分；喘息听距18米、每秒30分，和脚步取更强的可闻信号。距离衰减为 `(1 − 距离/听距)²`，听距之外不涨；隔墙或闭门听距缩至55%。听不到时每秒下降12分。近处蹲走也可能被听见，远处跑步不一定涨分。抽屉、开门、玻璃、配电箱与阀门按声音强度、距离和遮挡提供瞬时证据；丢石子会引导调查远处落点，不把落点直接当成玩家暴露。
- **灯光**：使用手电真实光锥、镜头俯仰和22米射程，墙、闭门和实体高柜遮挡有效。照中基础每秒20分，移开或关闭每秒下降25分。
- **视觉**：需满足朝向、发现距离、无遮挡及初始4秒视觉宽限。发现距离沿用原模型：追击19.5米、玩家亮灯13.5米、关灯站立9米、关灯蹲行5.7米；未追击时半视角约60度。真实可见时，3米内每秒60分，3–7米35分，更远20分；失去视线每秒下降25分。藏在未被目击的衣柜内不可见，高柜也会遮挡视线。

模拟与HUD共享这些读取接口；距离均以米显示。AI按当前实际线索的贡献选择循声调查、寻找光源或追查目击点，追击可由新声光线索更新位置，没有新线索时只能搜索记忆位置。

冻结10秒时，奶蛙的移动、转身、抓捕、感知分数变化与警觉计时均暂停，记忆保留；效果结束后继续。暂停或CG不消耗模拟时间。

## 行动、疲劳与界面

默认站立。短按C切换蹲行，Shift切换奔跑，二者互斥；手机同样点按切换。离柜和下一夜站立。旧版没有切换字段的柜外存档首次迁移也恢复站立，位置和物品保留。选中奔跑后体力耗尽时暂时步行，恢复到30再跑；暂停清空按键和摇杆输入，但保留选中模式。

疲劳独立于体力和声音分：实际步行/奔跑/蹲行每秒增加6/14/3，静止每秒下降20。100时开始喘息，下降到35以下停止；喘息是否暴露玩家仍由上述听觉距离模型决定。

默认只显示总暴露条。桌面Tab或手机“详情/收起”切换来源详情，偏好保存在独立的 `nwaxz-escape-hud-v1`，不改游戏会话或原IndexedDB存档。M仍打开地图，菜单内Tab仍切换焦点。详情显示三路分数、贡献分和占比、实际动作、距离、可闻/可见/光照命中和涨分速度；体力、疲劳、电量、水晶数量及计时另行显示。

实际发布与精确SHA见 [Issue #58](https://github.com/lingyunmo/nwaxz/issues/58)。浏览器自动化不等同于真实iPhone/微信扬声器和帧率验收；云端同步仍未实现。
