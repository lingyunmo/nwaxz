# 玩家界面文案

首页只展示浴场模式、逃生模式、对抗模式三个入口。浴场模式使用原普通模式封面，进入后选择泡泡浴场或午夜浴场，各自续关和成绩独立；原极限恐怖统一显示为逃生模式。对抗模式暂定为3v3 MOBA，只展示绘制预告封面和“筹备中”，不可开始或匹配。技术说明留在开发文档。

主菜单和浴场选择按实际视口铺满，横屏并排、竖屏纵排；不通过Fullscreen API强制首页全屏。关卡内既有全屏行为保持。内部模式标识和存档键不因玩家看到的名称变化而改变。

## 写法

- 按钮说清操作：进入模式、继续闯关、返回选关、备份存档。一个按钮只表达一个动作。
- 玩家能看见或听见的动作不再旁白解释。捧腹大笑直接播放，界面不写“奶蛙开心得捧腹大笑”。
- 行动反馈只报结果，例如“找到黄铜钥匙”。下一步线索放到暂停地图，不在每次拾取后拼接完整任务。
- 操作放在“操作／怎么玩”中，存档工具按需展开。不要用常驻大段文字反复教学。
- 玩法提示保持具体：说明哪种水、哪个机关、为何失败。关卡中的必要线索不为了简短而删除。
- 错误信息给出可执行的恢复办法。重置确认必须说明重置范围与保留的成绩；不能改成空泛氛围词。
- 不在游玩流程展示“原18关记录保留”“独立本地会话”“3D模型”等开发说明。实际备份范围仍要准确标注，避免误以为关卡备份包含逃生存档。
- 版本、离线状态和声音排障集中在设置。正常流程不堆叠技术状态说明。
