# 二楼晴窗休息室（本地候选）

值班室东侧新增入口和连续上升 4.8 米的十六级木楼梯，无需钥匙、供电或传送。二楼有奶油色墙面、鼠尾草绿沙发、软垫、地毯、茶桌、书架、窗边长椅、绿植及暖灯。东侧两组真实窗洞可以俯看楼下草地、花树、花园步道和三名散步的友好 NPC；窗台及家具保留实际碰撞，不能穿窗离开关卡。NPC 只属于窗外景观，不参与逃生目标。

- 安全区从第一节上行楼梯开始。奶蛙不能进入楼梯入口、上层平台或休息室，巡逻仍使用原一楼与负一楼的可达范围；追击最多接近值班室一侧。
- 上楼立即清除声音、手电、视觉暴露及警觉线索，总暴露值为零。已有仪表干扰立即解除，停留期间不发起新干扰；冻结期间同样有效。下楼后恢复普通感知和干扰周期。
- 奔跑、喘息、手电和丢石子不会在安全区引来奶蛙。二楼不触发抓捕、负一楼感测或瞬移；联机中休息的玩家不会成为追击线索，楼下队友仍正常受到追捕。
- 二楼减弱暗角、胶片颗粒和色散，使用独立日光与暖灯，不改变一楼及负一楼照明。窗外 NPC 随游戏时间活动，暂停时停住，“简化动作”启用时保持静止。休息时不播放奶蛙笑声或追击心跳。
- M 地图新增“二楼”书签，继续保留探索迷雾和当前楼层的玩家箭头。
- 逻辑地图向东扩展为 39 列，原房间坐标、目标链、道具及逃生出口不变。v2 会话新增可选 `mapWidth`；没有该字段的旧 25 列存档自动迁移已探索格与巡逻记忆索引，不清除进度。

实现：`src/escape/upstairs-map.ts`、`upstairs-scene.ts`，以及世界、地图、HUD 和渲染器的楼层接入。没有新增外部图片或角色素材依赖；界面粗体使用 Noto Serif SC 的 700 字重重新生成中文子集，继续随现有 OFL 许可证分发。

- `pnpm check`：358 项业务测试、TypeScript、生产构建和 2 项 PWA 检查通过。新增 `server/upstairs.test.mjs` 的 8 项测试覆盖真实上下楼、窗台碰撞、冻结中清除暴露/干扰、长时停留、现有多人权威追击、探索迷雾、旧 25 列存档索引迁移和窗外几何/动画；原单人、双人、三人完整逃生路线通过。
