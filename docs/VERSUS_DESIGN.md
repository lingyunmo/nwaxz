# 奶娃峡谷 · 归水礼

本批是可操作的客户端界面与设定图鉴，**不是可开局的 MOBA**。大厅参考成熟竞技游戏的“浏览角色 → 编队 → 锁定”流程，角色、美术、阵营与规则均围绕奶娃重新设计。现有浴场与逃生模式不变。

## 世界

奶娃峡谷坐落在一座古老的大浴场下游。归水礼那夜，分配冷热泉水的老泉枢停转，河心的大口吞下了断流的潮水。原本共用水渠的两岸分开立旗。

- **清泉盟**相信水应流回每一户门前，要重新打开旧闸。
- **暖炉会**守着高处的炉火与温泉，要让峡谷熬过长夜。

双方都生活着奶娃，都有正当诉求；英雄不锁阵营。野区也不塞入龙、狼等外来物种：老奶娃有自己的生活与规矩。

## 三席，不是三种职业

地图设定为**上渠、下渠两条推进通道，中央河心连接两岸**。每队三个位置：上渠守通道、下渠找推进机会、巡河串联河心与两渠。没有第三条单人中路，也不强行安排上中下五人分工。

每一术都能站任一席；位置负责空间分工，四术负责解题方式。客户端允许自由试阵，同队一只奶娃只占一席；四只初始奶娃不足六只，因此两岸可镜像选角。当前没有禁用、排位、自动补位、匹配或真人选角倒计时。

## 原创四术

**引潮 → 封闸 → 回响 → 隐沫 → 引潮**。箭头表示在条件成立时，有一个可操作的机制解法；不表示全程伤害乘区。对角两术中性，同术没有额外优势。

| 术 | 核心问题 | 对下一术的解法 | 仍需承担的风险 |
| --- | --- | --- | --- |
| 引潮 | 怎样把水路变成进退路线 | 蓄势水流冲开临时闸墙 | 蓄势可打断，锁定水流会追错假身 |
| 封闸 | 怎样截断关键水线 | 断水阻止回响传导 | 不能永久封路，已经蓄足的引潮能破闸 |
| 回响 | 怎样辨认真身与踪迹 | 声纹识破隐沫假身 | 声波可躲，离开水面或截流可减少追踪 |
| 隐沫 | 怎样让对手做错判断 | 假身诱走锁定水流 | 假身有迹可辨，也会被回响识破 |

平衡原则：不能“选到克制就赢”。每一招要有读条或前摇、可辨的范围、可行的反制窗口；具体数值由未来战斗原型验证，本批不编造伤害、胜率和冷却数字。

## 未来单局原型的边界

拟采用固定俯视真 3D、短局 3v3、两渠闸塔到敌方泉枢的推进目标；泉压作为局内争夺资源，是否增设小型搬水奶娃与复活规则需原型测试。先验证移动/技能读招/一条水线的交互，再验证六人同步和完整地图。不得把本批 UI 中的技能介绍当作已实现战斗。

## 本批可操作范围

大厅角色切换；四术筛选；P/Q/E/R 招式页；两岸三席选角、同队换位、锁定/解锁；明确标为“示例阵容”的本机填充；本机昵称；刷新恢复编队；四术关系图；地图场所与中立奶娃图鉴；离线资源。页脚持续显示“界面预览 · 对局尚未开放”。
